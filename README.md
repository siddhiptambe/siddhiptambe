## 🚀 Featured Projects

### 1. Emotion-Aware Fake News Detection

An AI-based approach to fake news detection using textual representations, speaker credibility, and emotion-related features from the LIAR benchmark.

**Focus Areas:** NLP, Text Classification, Emotion Feature Fusion, Deep Learning, Transformers.

### 2. BhoomiTrack – Land Acquisition & Management System

A GIS-based platform designed to support land acquisition and management through geospatial data, route analysis, and parcel-level insights.

**Focus Areas:** React, GIS, Leaflet, PostGIS, Supabase, Geospatial Analysis.

### 3. Piston Cult

A web platform for automobile enthusiasts featuring vehicle listings, an accessories marketplace, automotive news, community interaction, authentication, and real-time buyer-seller chat.

**Focus Areas:** Full-Stack Development, E-commerce, Real-Time Communication, Database Management.

### 4. TechMonopoly

A technology-themed interactive multiplayer board game combining quiz-based challenges, property management, and technology-related knowledge.

**Focus Areas:** React, Tailwind CSS, Node.js, Express.js, Supabase.
